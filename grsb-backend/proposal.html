Website Remodel Proposal

A modern public site with an update workflow volunteers can actually maintain

Why Remodel

The current site is overdue for a cleaner public face

The proposed site gives the Grand Rapids Symphonic Band a polished, mobile-friendly home for concerts, tickets, auditions, youth soloist information, donations, recordings, and contact details.

It uses the assets prepared in this folder, including the band logo, ensemble photography, conductor photography, donation QR code, and locally bundled fonts.

Admin Workflow

How updates work

Today, a webmaster can open the editor, update site settings, concerts, or audio tracks, validate the fields, and download replacement JSON files on the static preview.

With GitHub-backed Sites secrets or Node-capable hosting configured, the same editor detects the backend, enables Save buttons, and persists updates through token-protected API endpoints.

Recommended next steps

  1. Review the proposal site on desktop and mobile.
  2. Choose the long-term host and repository owner.
  3. Configure the GitHub-backed API or deploy the Node backend, then set the admin token.
  4. Point the official domain after approval.
