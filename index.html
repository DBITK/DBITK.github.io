Projects

Golden Path (derekbartlett.com/golden-path-pipeline)

A deployment pipeline that decides statistically whether a build is allowed to reach production. Each environment deploys a fresh baseline alongside the candidate, drives identical load through both, and judges the result with a Mann-Whitney U test and effect-size gate before performing a red/black traffic switch. Compiles to Argo Rollouts manifests.

Self-hosted Homelab

Single-server Proxmox host with RAID 1 storage. TrueNAS, Jellyfin, Sonarr stack, Home Assistant, Pi-hole. Treated personal kit like prod — segmentation, snapshots, and recovery drills.
