Projects

Representative systems I’ve built, operated, or used to sharpen platform engineering skills.

  • Golden Path — live, try it

    A deployment pipeline that decides statistically whether a build is allowed to reach production. Each environment deploys a fresh baseline alongside the candidate, drives identical load through both at the same time, and judges the result with a Mann–Whitney U test and an effect-size gate before performing a red/black traffic switch — the automated canary analysis Netflix built Kayenta for, implemented from scratch rather than described.

    The delivery config is declarative: teams state requirements and the orchestrator derives the steps. A weekly drill deliberately ships broken builds and fails if they get promoted. The same config compiles to Argo Rollouts manifests, because the methodology outlived the tool it came from.
